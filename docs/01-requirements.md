# 需求、权限与验收

## 1. 范围

六大模块均纳入交付。增加组织、用户、药品基础资料和简化临床业务作为支撑模块。外部数据导入采用 Excel 模板；“自动获取”由本项目字典、患者和临床记录关联带出。外部 HIS 与财务连接器定义输入输出模型，课程第一版通过本地录入完成流程。

支持西药、中成药、中药饮片和院内制剂。原辅料及包装材料具有独立物料类型。制剂产品可映射为药品，供药库和药房接收入库。医保维护类别、编码和自费标志；课程收费按处方金额记账，不计算真实医保结算待遇。

## 2. 角色与数据范围

| 角色 | 主要权限 | 数据范围 |
| --- | --- | --- |
| 管理员 | 组织、账号、角色、权限、配置、模板、数据字典、演示数据管理 | 全院；业务操作仍须授予业务权限 |
| 药库管理员 | 采购、入出库、调拨、盘点、报损、退供、库存查询、日结 | 分配的药库 |
| 门诊药师 | 处方审查、复核、发药、退药、药房领药与库存 | 分配的门诊药房 |
| 住院药师 | 医嘱确认、摆药、统领、发药、住院退药和库存 | 分配的住院药房及关联病区 |
| 药品会计 | 调价、对账、报账、凭证、付款审核、全院统计与结账 | 全院账务，可查询相关库存 |
| 制剂人员 | 原料、配方、生产、质检、成本和制剂库库存 | 分配的制剂库与生产业务 |
| 医生 | 患者、就诊、诊断、处方、医嘱和审查结果查询 | 分配科室及本人创建的临床单据 |

账号可以分配多个角色。权限细分为查看、新增、修改、提交、审核、执行、冲销、调价确认、收费、退款、欠费放行、结账、导出等动作。

简化收费由有 `clinical:payment:create` 权限的演示账号执行，可通过给管理员配置此权限完成，不额外建立收费员角色。质检、生产执行、生产审核是制剂角色下的独立权限，用不同账号演示岗位分离。

机构范围绑定到账号及库房/药房/科室。选择当前机构只改变工作上下文，后端每次验证实际授权。不能通过修改请求中的库房 ID 查看或操作其他库房。

通用库存、采购、价格单据的审核人不得为制单人。门诊复核者不得为发药者；控制药品还要求登记及独立复核。提交者与发药者可以是同一人，前提是业务所要求的独立审核已完成。管理员也不自动绕过双人规则。

## 3. 功能对照

### 3.1 药品库房

| 原需求 | 设计功能 | 验收证据 |
| --- | --- | --- |
| 1、11：信息、医保、字典与别名 | 药品、剂型、规格、厂家、供货商、单位换算、价格、医保、成分、特殊分类；别名搜索与导入匹配 | 用通用名、商品名、别名查到同一药品；歧义匹配要求人工选择 |
| 2：自动采购 | 按库存上下限与近期消耗计算建议，选择供货商生成计划和采购单 | 缺货品种生成建议并能调整、审核 |
| 3、4：入出库及特殊业务 | 普通采购、赠药、实验药、退供、调拨、盘点、报损丢失、领用退回 | 执行后产生对应批次流水，特殊药品可单独查询 |
| 5：结算与平衡 | 日、月、年结，数量账、采购成本账和零售估值账核对 | 可查询期初、发生额、期末及差异 |
| 6、7：明细与流水 | 单据明细和汇总；药品、批号、库房、日期、操作者过滤流水 | 任一品种从入库到出库可追溯 |
| 8：科室领药 | 科室或药房提交申请后自动进入药库待办 | 无须药库重复录入申请明细 |
| 9：药房核算 | 药房消耗、库存、调拨在途和退药分析 | 多药房数据可比较且全院不重复计入内部调拨 |
| 10：单据格式 | 配置字段、顺序、列宽、标题、纸型、签字栏 | 不同单据类型可预览及打印 |
| 12、13：有效期与特殊分类 | 效期预警、过期品种数/金额、低库存、毒麻精神、贵重、院内、进口、自费标签及规则 | 过期发药被阻断，控制药品缺登记被阻断 |
| 14、15：批次及多级 | 同一药品多批次、多库房；药库 → 药房 → 科室基数药 | 库房维度数量与全院汇总一致 |

### 3.2 门诊药房

| 原需求 | 设计功能 | 验收证据 |
| --- | --- | --- |
| 1、2：资料与划价 | 患者就诊、医生录入处方；药品字典带出医保、单位、来源、价格 | 划价金额由服务端重新计算 |
| 3、5、15：核对、控制、双审 | 审查、冻结价格、缴费、批次分配、药师复核、另一药师发药 | 已缴费且复核通过才可发药；日处方量按类型统计 |
| 4：为住院患者发药 | 住院医嘱可指定门诊药房为执行机构，沿用住院费用和执行单 | 无须把住院医嘱伪造成门诊处方 |
| 6：金额对账 | 收费、待发药、已发药、退药退款分类对账 | 已缴未发作为时间差展示，不直接判错 |
| 7、8：申请与接收 | 自动补货申请；药库发货后药房确认接收 | 发货进入在途，确认后增加药房库存 |
| 9：调拨、盘点、报损、调换、退药 | 共用库存引擎；调换用关联退回/重新发出单 | 两笔单据可关联追溯，差价独立结算 |
| 10、11：结算与查询 | 日月年结、时间段消耗、入出存明细 | 汇总与明细相符 |
| 12—14：效期、特殊、多药房、批次 | 与药库共享规则，机构独立配置阈值 | 多药房互不越权，按批次选择发药 |

### 3.3 住院药房

| 原需求 | 设计功能 | 验收证据 |
| --- | --- | --- |
| 1、2：医嘱、上账与摆药 | 临时/长期医嘱、频次、起止时间、特殊和隔日计划，执行实例确认、记账、分类摆药、统领单、中草药处方打印 | 同一医嘱同一计划时间只能生成一次；押金变化可追溯 |
| 3：基数药 | 病区作为库存位置，核定基数、申领补充、消耗登记、退回、统计 | 发往病区与病区消耗不重复记成本 |
| 4：出库查询 | 按患者、病区、医嘱、分类、批次查询和打印 | 从发药记录追溯医嘱及费用 |
| 5—8：库存、效期、多个药房、批次 | 复用申请、确认、调拨、盘点、报损、退药、结账、控制药登记 | 库存与住院发药账一致 |

### 3.4 药品会计与价格

| 原需求 | 设计功能 | 验收证据 |
| --- | --- | --- |
| 1、2：价格与调价盈亏 | 购进价、零售价、折扣及加成参数；文件依据、原因、生效时间；自动/手动确认；全院调价与估值变化 | 新交易使用新价，原交易价格快照不变 |
| 3：共享与报账 | 库存及收费数据生成凭证草稿，自动/手工过账；可导出财务交换数据 | 凭证源单据唯一，借贷平衡 |
| 4：核对及综合加成 | 库存成本与估值、发药销售净额、收退款、购入、消耗、月综合加成率 | 收入、实收、成本及时间差定义明确 |
| 5、6：统计 | 月季年分析、科室消耗、库房药房库存与周转 | 按执行日期计算且关联到明细 |
| 7：打印输出 | 库存账、收支、调价、凭证及报表打印、Excel | 输出与页面过滤范围一致 |

### 3.5 制剂

| 原需求 | 设计功能 | 验收证据 |
| --- | --- | --- |
| 1、2：物料及产品 | 原辅料、包装、半成品、成品入出库、领用、销售、盘点、报废 | 统一库存引擎区分物料类型和阶段 |
| 3—5：账务、成本、输出 | 月收支、成品发出、原料明细、材料月消耗、领用清单；成本结算和凭证 | 成本由实际领料及人工能源费用汇总 |
| 6：质控 | 原料质量、卫生学检测、成品检测；合格、不合格和隔离 | 未合格批次不能用于生产或发出 |
| 7：采购与付款 | 计划、采购、应付、分次付款与余额 | 付款不超过可付余额，赠送无应付 |
| 8、9：定额与生产 | 配方版本、工序、工时、产量、水电气标准和实际、生产批记录 | 可对比定额与实际，成品可追溯原料批次 |

### 3.6 合理用药

| 原需求 | 设计功能 | 验收证据 |
| --- | --- | --- |
| 1a：过敏 | 患者过敏史关联药品、成分、药物分类 | 示例过敏处方阻断审核 |
| 1b：相互作用 | 成分或药品对、严重度与处理说明 | 两药互换顺序检查结果一致 |
| 1c：剂量 | 药品/成分剂量、单位、年龄及体重条件 | 单次量、日量超范围提示；缺体重提示资料不足 |
| 1d、1e：禁忌与适应症 | 诊断编码与药品规则匹配 | 禁忌触发、未匹配适应症提示并可解释 |
| 1f：重复 | 别名统一和成分叠加 | 两商品名含同一成分触发重复提示 |
| 2、3：咨询 | 用法用量、注意事项、指南、不良反应、相互作用资料 | 检索可查看来源、版本和示例标记 |

## 4. 跨模块验收

所有业务支持分页、过滤、详情和操作轨迹。已执行记录不可删除；基础资料被引用后只能停用。处方、医嘱及打印包含患者与医生快照，药品停用不影响历史。

系统同时展示“实际库存、预留库存、可用库存、在途库存”，所有数量标明单位。区分“采购成本金额、零售估值、实际收费”，不同金额不会混为一个库存金额。

检查并发超卖、重复执行、跨机构访问、越权审核、已结期间回写以及退款超额等异常路径。课程演示账号至少包含两个不同的门诊药师和两个制剂业务账号。
